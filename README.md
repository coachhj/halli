# 할리갈리 숲

각자 폰으로 접속해서 함께하는 온라인 할리갈리.

- 방장이 "새 방 만들기" → 숫자 4자리 방 코드, QR, 링크로 친구 초대
- 최대 8명 (AI 팀원 최대 2명)
- 같은 과일이 정확히 5개면 벨! 틀리면 카드 1장이 바닥으로
- 방장이 게임 방식 선택: 시간제 5분·10분 / 한 명 탈락까지 / 최후의 1인 (최대 10분)

방장 기기가 심판 역할을 하므로, 방장은 게임 내내 화면을 켜 두세요.
방장이 새로고침하거나 잠깐 다른 앱에 다녀와도 같은 방으로 이어서 할 수 있어요.

연결은 Firebase Realtime Database(halligalli 프로젝트)를 거쳐요.
